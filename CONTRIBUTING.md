# Contributing

Contributions are welcome.

1. Keep the app local-first and do not add hidden telemetry or remote inference.
2. Preserve the `127.0.0.1`-only default binding.
3. Do not commit model weights, generated media, logs, or private photos.
4. Keep README assets appropriate for a general-purpose open-source repository.
5. Test both text-to-image and image-to-image request paths before opening a PR.

Please include the ComfyUI version and relevant hardware details when reporting
compatibility issues.
